Questions fréquentes

Comment contacter le support ?

Écrivez à allankleinpro@gmail.com.

Comment supprimer mon compte ?

Dans Youemi, ouvrez Profil, puis Supprimer le compte. Vous devrez saisir votre mot de passe. Retrouvez les détails sur la page Supprimer votre compte.

Pourquoi Youemi demande-t-elle ma localisation ?

La localisation est utilisée uniquement si vous la choisissez, afin de placer les lieux sur votre carte de couple. Vous pouvez la refuser ou la modifier à tout moment dans les réglages de votre appareil.

Quels contenus mon partenaire peut-il voir ?

Les contenus que vous partagez volontairement dans l’espace de couple sont visibles par le partenaire associé à cet espace.
